Bioinformatics Analysis of Human Angiotensin-Converting Enzyme (ACE) Gene using Python and Biopython

About the Project

This project focuses on the computational analysis of the human Angiotensin-Converting Enzyme (ACE) gene using Python and the Biopython library.

The reference DNA sequence was retrieved from the NCBI Nucleotide database. I used Python to examine its nucleotide composition, calculate GC and AT content, extract the coding DNA sequence (CDS), and translate it into a protein sequence.

This project helped me gain practical experience in biological sequence retrieval, DNA sequence analysis and basic bioinformatics programming.

Project Objectives

- Retrieve the human ACE gene reference sequence from NCBI.
- Analyse the nucleotide composition (A, T, G and C).
- Calculate GC and AT percentages.
- Extract the annotated coding DNA sequence.
- Translate the CDS into an amino acid sequence.
- Compare the translated protein with the NCBI reference protein.
- Visualise nucleotide composition using a bar graph.
